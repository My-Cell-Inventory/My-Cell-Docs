# Definition of Done

Una contribución documental está lista para integrar cuando el índice enlaza los documentos, las referencias funcionan, los cambios tienen revisión por otra persona y el PR incluye la evidencia correspondiente.

Para una historia de producto, confirma además:

- Los criterios de aceptación y las reglas de negocio asociadas tienen evidencia de validación.
- Cuando corresponda, se verificaron permisos en servidor, aislamiento por local y consistencia de stock y caja.
- Los documentos afectados se actualizaron según la [matriz de impacto](docs-touchpoints-matrix.md).
- La evidencia identifica ambiente, versión, casos y resultados. Consulta [Evidencias](../11-quality/evidence/README.md).
