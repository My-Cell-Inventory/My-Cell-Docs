# Glosario

| Término | Uso en MY CELL |
| --- | --- |
| Nombre de producto | Identificador único que se compara ignorando mayúsculas, tildes y espacios de más. |
| Carga | Registro de una entrega de proveedor con documento y líneas de mercancía. |
| Producto pendiente | Producto nuevo sin precio, aún no disponible para venta. |
| Stock | Unidades disponibles calculadas a partir del inventario inicial y los movimientos. |
| Costo promedio | Costo ponderado de las existencias y las nuevas entradas por local. |
| Margen | Porcentaje de ganancia sobre el costo del producto. |
| Kardex | Historial de movimientos de un producto. |
| Caja | Ingresos menos egresos del local. El cierre compara lo esperado con lo contado. |
| Dañado | Producto dañado por el personal. Requiere vendedor responsable y se valora al costo. |
| Garantía | Defecto de fábrica atendido dentro del plazo de la venta. Se contabiliza por separado. |
| Faltante / sobrante | Diferencia entre el stock calculado y lo contado físicamente. |
| CSV | Archivo tabular para importar mercancía o exportar reportes. |
| SMTP | Protocolo usado para enviar correo. |
| Bitácora | Registro de quién realizó qué acción, en qué local y cuándo. |
| Dueño Principal | Cuenta inicial creada con datos semilla, con todos los permisos y sin opción de desactivación. |
| Dueño secundario | Dueño con acceso a los módulos habilitados por el Principal. |
| Código de verificación | Código de seis dígitos enviado por correo para recuperar la contraseña. |
